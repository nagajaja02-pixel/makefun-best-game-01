Emberfall is a wave-based survival arena game: play the last ember-warden, hold the Hollow against rising waves, collect shards, level up and draft upgrade cards — and face the Hollow King every fifth wave.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`.
